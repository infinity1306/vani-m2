# Screen Capture Specification

## 1. Overview
The Screen Capture Capability captures screenshots of displays or individual windows with structured metadata.

## 2. Capabilities
- `screen.capture`: Captures screen image buffer (`png`/`raw_rgb`) with metadata (`timestamp`, `monitor_id`, `window_id`, `resolution`, `source`).

## 3. Privacy Policy
- Captured images are kept in memory or local storage.
- Screenshots are NEVER automatically uploaded or sent to third-party cloud services without explicit user consent.
