# Window Management Specification

## 1. Overview
The Window Management Capability inspects and manipulates desktop application windows.

## 2. Capabilities
- `window.list`: Lists open top-level windows with title, rect, monitor, and state.
- `window.focus`: Brings window to foreground focus.
- `window.minimize`: Minimizes window to taskbar/dock.
- `window.maximize`: Maximizes window.
- `window.restore`: Restores window from minimized/maximized state.
- `window.resize`: Sets window position and dimensions.
- `window.close`: Closes a specific window.
