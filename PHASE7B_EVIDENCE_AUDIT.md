## 14. HONEST ASSESSMENT OF KNOWN LIMITATIONS

In strict adherence to the GSD principles of empirical honesty:

1. **Tool Execution Isolation:**
   - `IN_PROCESS_EXCEPTION_CONTAINMENT = YES`: Tool exceptions are trapped via structured `Result<T>` and C++ exception handlers without crashing the runtime.
   - `OUT_OF_PROCESS_ISOLATION = NO`: Tools execute within the runtime process address space rather than in sandboxed child worker processes.
2. **Local LLM Availability:**
   - The agent requires the local Ollama daemon to be active on `127.0.0.1:11434`.
   - If Ollama is offline, the agent cleanly rejects planning with `ErrorCode::Unavailable` (`AGENT_UNAVAILABLE_OFFLINE`), and does NOT silently spoof model responses.
3. **Local LLM Cold-Start Latency:**
   - First-token latency on small local models (`qwen2.5:3b`, `llama3.2:1b`) ranges between 1.5s and 9.2s on consumer CPU/GPU hardware.
